# Инструмент визуализации графа зависимостей (Вариант №10)

## 1. Общее описание
Консольное приложение (CLI) для анализа прямых, транзитивных и обратных зависимостей пакетов формата **Alpine Linux (`apk`)** без использования сторонних библиотек и менеджеров пакетов. Инструмент скачивает и распаковывает индекс `APKINDEX.tar.gz`, строит граф зависимостей алгоритмом нерекурсивного поиска в глубину (DFS) с учетом фильтрации и циклических связей, генерирует описание диаграммы на языке **D2** и открывает визуализацию графа в браузере.

## 2. Описание всех функций и настроек

### Параметры командной строки:
* `--package <имя>` — (обязательный) имя анализируемого пакета.
* `--repo <url_или_путь>` — (обязательный) URL-адрес репозитория Alpine Linux или путь к файлу тестового репозитория.
* `--test-repo` — (флаг) режим работы с локальным тестовым файлом описания графа, где пакеты названы заглавными латинскими буквами.
* `--filter <подстрока>` — исключает из анализа пакеты, имя которых содержит указанную подстроку.
* `--reverse` — выводит обратные зависимости (пакеты, которые зависят от данного пакета).
* `--web` — автоматически открывает сгенерированную D2-диаграмму графа на сайте в браузере.

### Основные функции модуля `src/dep_viz.py`:
* `build_parser()` — конфигурация CLI-парсера `argparse`.
* `validate_args(args)` — валидация аргументов и проверка существования файлов.
* `fetch_apkindex_text(repo_source)` — скачивание и распаковка `APKINDEX.tar.gz` в памяти.
* `parse_apkindex_graph(index_text)` — парсинг полей `P:`, `D:`, `p:` и разрешение виртуальных зависимостей (`so:`, `cmd:`).
* `parse_test_repo_graph(file_path)` — чтение тестового графа из файла.
* `build_dependency_subgraph_dfs(full_graph, start_pkg, filter_substr)` — построение транзитивного графа алгоритмом DFS без рекурсии.
* `find_reverse_dependencies(full_graph, target_pkg, filter_substr)` — поиск обратных зависимостей по инвертированному графу через нерекурсивный DFS.
* `generate_d2_diagram(subgraph)` — генерация кода диаграммы на языке D2.
* `build_web_diagram_url(d2_text)` — кодирование диаграммы D2 для открытия графа в браузере.
